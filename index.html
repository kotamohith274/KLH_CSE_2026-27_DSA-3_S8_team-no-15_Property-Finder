How the search engine works

🔎 Wagner–Fischer (fuzzy location)

Classic dynamic-programming edit distance between your typed location and each listing's locality. similarity ≥ 0.55 counts as a match, so typos like Gachiboli still find Gachibowli. Runs in O(m·n).

⚡ KMP (keyword search)

Knuth–Morris–Pratt scans titles + descriptions for your keyword in linear time O(n+m) using the LPS failure table — no re-scanning, every occurrence counted for ranking.

🏷️ Aho–Corasick (amenity tags)

All 14 amenity phrases are compiled into one trie with failure links, then every listing is scanned once to tag amenities — O(text + patterns + matches) instead of 14 separate scans.
